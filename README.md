# Sistema de Gestão Imobiliária

> 🚧 Projeto em desenvolvimento

Sistema desenvolvido em Python com o objetivo de gerenciar imóveis, proprietários, inquilinos e contratos de locação.

Este projeto está sendo desenvolvido como parte dos meus estudos em Programação Orientada a Objetos, modularização e banco de dados.

---

## Tecnologias

- Python 3
- Programação Orientada a Objetos (Próximo passo)
- SQLite (em desenvolvimento)
- Git
- GitHub

---

## Funcionalidades implementadas

- [x] Cadastro, Listagem, Exclusão e Edição de proprietários
- [ ] Cadastro, Listagem, Exclusão e Edição de imóveis
- [ ] Cadastro, Listagem, Exclusão e Edição de inquilinos
- [ ] Cadastro, Listagem, Exclusão e Edição de Contratos
